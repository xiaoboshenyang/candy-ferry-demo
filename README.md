# 糖果摆渡｜试玩

19个母题、76道题，每母题4道。120秒一局，鼠标左键或手指按住滑动，整条刀轨可连续切断多根绳；糖果进入狐狸碗口过关。星星每颗加5分。

当前题面：尖刺长度至少64；点位和整个接绳圈外缘与狐狸图像至少留24净空。题号可用 `?qid=M014-V4` 固定，审题页为 `data/review.html`。

本仓库包含独立静态试玩所需的页面、题库及资源。使用任意静态HTTP服务器即可运行，也可将GitHub Pages发布来源设为codex/github-preview分支根目录。

试玩等级为当前题池的相对分级，仍待真实用户验证。源码及项目素材未声明开源再授权；音乐许可见licenses/BGM-044.txt。
